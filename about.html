About TravelSense

A simple web app that brings together weather and country data for any destination worldwide.

How it works

1

Enter a city

Type any city name in the search bar and press Enter or click Search.

2

Data is fetched

The app queries two cloud APIs in sequence: Open-Meteo for weather data and REST Countries for country information.

3

Results are displayed

Current weather, 7-day forecast and detailed country info are shown instantly on screen.

APIs used

⛅

Open-Meteo

No API key required

Free and open-source weather API. Provides geocoding (city → coordinates), current weather conditions and daily forecasts using WMO weather codes.

open-meteo.com →
🌍

REST Countries

No API key required

Public API with data on every country in the world: name, capital, population, area, currencies, languages and flag images.

restcountries.com →
